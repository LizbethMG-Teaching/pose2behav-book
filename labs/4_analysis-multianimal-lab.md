# Lab 4: Multi-animal analysis

## Introduction 🐭🐭🐭📈

Using multi-animal pose data from SuperAnimal DLC, you will explore how active each mouse is, how they use space, how social they are, and how they behaved. By the end, you will generate a medal table that crowns the top performers in each behavioral category.

## 🎯 Goals

After completing this notebook, you will be able to:

- Load and preprocess multi-animal pose data from SuperAnimal DLC
- Compute activity metrics per mouse such as speed, distance, rest and movement bouts
- Compute spatial metrics such as area usage and occupancy
- Compute social metrics such as time spent near others and pairwise interaction frequency
- Integrate all metrics into a clean and comparable summary table
  
## 📂 Deliverables

By the end of the lab, you will submit:

- A Jupyter notebook containing all code and visualizations
- A summary table with one row per mouse and one column per metric
- A final medal plot showing category winners
